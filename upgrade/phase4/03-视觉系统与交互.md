# P4.0｜全新三主题视觉系统与桌面交互

状态：设计候选，等待用户审阅；本轮只交付静态样例，尚未实现正式客户端。依据为 [P4.0 任务](https://www.notion.so/41a5421e690b813b8004c9495eed1027)、[2.0 正典](https://app.notion.com/p/4135421e690b815eb404c3024c860134) 的 2026-11-16 最新裁定，以及 main `3c7a778` 源码。旧 Android 定稿和旧 React 页面只提供功能语义，均不是新 Desktop 的页面模板。

## 1. 视觉方向：安静的工作台

三栏的结构通过底色、边界与留白成立，不把每块内容都放进圆角卡片。中间对话是视觉重心；Navigation 紧凑、Inspector 克制。抹茶绿用于品牌、选中、可操作重点和焦点，正文保持高对比。辅助状态有文字与图形提示，Diff 同时用 `+ / −` 表达增删。

已定案：独立 Tokens + Tailwind CSS、新的 Light / Dark / OLED Dark、Oracle Eye、Navigation / Conversation / Inspector；完全舍弃旧 Trusted CSS Themes、Theme API v1、主题导入、旧主题引擎与迁移。P4.0 不删除任何历史文件。**本方案不向 `apps/web` 注入样式，不引用旧 CSS，不接入正式 Electron。**

建议细节：首次 Light，之后恢复本机选择；不新增第四主题。页面的具体密度、文字层级和绿色情绪是本次待审阅的设计内容，不把它们表述为已获用户视觉批准。

## 2. 可直接审阅的静态原型

入口：[prototype/index.html](prototype/index.html)。HTML / CSS / JS 无依赖，可本地直接打开；本轮自动浏览器检查使用只映射 `prototype/` 的随机 loopback 静态 HTTP 预览。该预览不是 Gateway、没有 API，也没有客户端业务实现。顶部始终标注“静态设计原型 · 全部数据为样例 · 无真实连接”。

| 入口参数 / 操作 | 已有静态表达 |
| --- | --- |
| 默认或 `?theme=light&scene=conversation` | Light 三栏、样例导航、用户消息、回复、执行摘要、Composer、只读 Diff |
| `?theme=dark&scene=conversation` | 同一工作区 Dark，对比三主题时不换布局 |
| `?theme=oled&scene=conversation` | 同一工作区 OLED Dark，三栏基础底均为纯黑 |
| `?scene=approval` | 单次命令审批样例；完整命令、原因、目录、网络上下文；允许/拒绝均禁用 |
| `?scene=offline` | 离线阅读、unknown 说明、当前会话写入阻断、草稿可输入、原操作核实入口占位 |
| `?scene=connect` | 首次连接与配对布局；loopback 地址占位、配对码占位、连接说明；无真实凭据 |
| `&panel=diff/files/process/usage/extensions` | Inspector 变更、文件/成果、执行/Plan/子代理、Token/额度、MCP/Skills/Apps/Plugins 样例 |
| 顶部主题按钮、场景下拉 | 即时切换设计样例，不保存偏好 |
| 导航搜索、Inspector 页签/收起 | 只过滤样例会话文字或切换可见内容；不访问真实历史 |

所有真实业务动作均禁用，或只出现“视觉预览，未执行操作”提示。不会创建会话、发送消息、审批、复制敏感内容、上传、下载、配对或修改权限。页面采用 `connect-src 'none'`；JS 无 fetch/WebSocket/Electron IPC/数据库/存储调用。脚本不持久保存输入，新打开页面无草稿；浏览器自身可能在刷新时恢复表单，不代表已实现客户端草稿持久化。

## 6. 键鼠、焦点与恢复

| 操作 | 交互设计 | 静态原型范围 |
| --- | --- | --- |
| Enter / Ctrl+Enter | Enter 换行，Ctrl+Enter 发送；输入法组合中不发送。保留成熟行为，提示常驻 Composer 下方 | Enter 可输入；Ctrl+Enter 仅显示不会发送的提示 |
| Ctrl+K / Ctrl+N | 搜索会话 / 新会话入口；最终需同时验证菜单、系统快捷键冲突与 IME | Ctrl+K 聚焦样例搜索；Ctrl+N 仅提示，无新会话 |
| Inspector 页签 | Tab 进入当前项，左右循环，Home/End 首尾，Tab 继续进入 panel；参照 [W3C Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) | 已实现静态页签键盘与 aria 状态 |
| Inspector 开关 | 保留当前会话、草稿、阅读位置，重开回原页签 | 只隐藏/显示静态 Inspector，不实现持久化 |
| 分隔条 | 指针拖拽；可聚焦，左右键调宽并读出值；可恢复默认布局 | 仅设计，未实现 |
| 弹窗 / 菜单 | Esc 逐层关闭；模态 Tab 限域；关闭回触发点；破坏性默认取消 | 没有模拟完整业务弹窗；Esc 仅关闭静态提示 |
| 右键 / 悬停 | 会话动作和复制入口可发现；关键审批不能只藏在 hover/右键菜单 | 原型操作菜单只有无操作提示 |
| 恢复内置外观 | 原生菜单与 Ctrl+Shift+0 独立于 renderer CSS；只恢复新三主题/字号/布局必要偏好 | 仅设计；不调用旧主题引擎、不清凭据/草稿/unknown。参照 [架构与安全设计](01-架构与安全设计.md) |

窗口关闭按产品语义退出客户端；无 Tray，也不停止 Gateway 或 Codex。页面退出与取消执行不能合并为一个动作。正式通知、拖拽、缩放、GNOME/Wayland 焦点与系统文件选择的验证留给 P4.4；静态浏览器截图不能代替 Ubuntu 打包客户端或 OS sandbox 证据。
