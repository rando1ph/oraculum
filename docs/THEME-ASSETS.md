# Theme acceptance assets

These are capability proofs, not replacement official Oracle Eye artwork.

- `themes/hong-kong-rain/assets/rain-night.webp`: original fictional Hong Kong inspired illustration generated for this project with the built-in imagegen tool on 2026-10-22; converted from PNG to WebP for package size. It is not a photograph or a representation of an identified real street. No third-party reference image was supplied.
- `themes/hong-kong-rain/assets/DejaVuSansMono.ttf`: unmodified DejaVu Sans Mono from Ubuntu's `fonts-dejavu-core`. Copyright © 2003 Bitstream, Inc.; DejaVu changes are public domain. The full Bitstream Vera font license is included in the theme.css comment and travels with the installed package. Used for Latin typography; Chinese characters use the device's fallback font. Project: https://dejavu-fonts.github.io/.

Image generation prompt (built-in tool):

> Use case: stylized-concept. Asset type: original background illustration for a trusted local CSS theme named Hong Kong Rain, not a UI mockup. Create a wide cinematic 1536x1024 digital illustration inspired by Hong Kong streets on a rainy night: dense stacked tenement facades, narrow street canyon, cantilevered vertical neon signs with simple traditional Chinese characters 雨夜 and 茶, wet asphalt reflecting teal cyan and hot pink neon, distant warm amber windows and soft atmospheric haze. Clearly a fictional artistic impression rather than a photograph or an identifiable real street. Dark navy and petrol blue base, saturated but restrained highlights, sophisticated cyberpunk mood, generous dark areas suitable beneath translucent reading panels. Perspective toward the center, buildings and signs on the sides, wet reflective foreground. No people close up, no logos, no app interface, no border or watermark. Opaque background.
