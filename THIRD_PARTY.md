# Third-party and brand resources

[LICENSE](LICENSE) applies to original Oraculum 2.0 code. The Oraculum name,
Oracle Eye marks, approved brand artwork and design references retain their
existing rights. The Desktop distribution uses the approved Outline Oracle Eye
and application icon under the Oraculum project identity. Third-party reuse of
these assets is subject to the applicable rights and permissions.

Desktop ships the pinned Electron distribution under the Electron and Chromium
licenses. Both upstream license files are installed under
`/usr/share/doc/oraculum-desktop/`. The same directory contains the project
license and notice, plus the licenses and notices collected from the packages
used in the bundled renderer, main process and preload. System libraries and the
desktop keyring are supplied by Ubuntu.

The official Codex App Server and protocol sources retain their upstream terms.
Oraculum generates local official protocol inputs under `.local/codex-protocol/`
and communicates with the App Server through its documented interface. The
Desktop package ships neither the Codex CLI nor the App Server. Existing
[Gateway](packaging/licenses/manifest.json) and
[Android](packaging/licenses/android/manifest.json) third-party records document
those components separately.
